# User Stories

This document tracks the product's user stories as a living backlog reference.
It complements `docs/backend-architecture.md`, `docs/frontend-components.md`,
and `docs/reservation-providers.md`, which cover the how; this file covers the
who/what/why.

## Core stories

1. As a user, I can explore and geo-visualize points of interest — campgrounds,
   Tesla Superchargers, and Planet Fitness locations — on a map.
2. As a user, I can drill into a campground to view its individual campsites
   and their availability.
3. As a user, I can see Tesla Supercharger rates and labeled context (stall
   count, amenities, etc.) for a location.
4. As a user, I can plan a route between two points and view that route on
   the map.
5. As a user, I can filter campground availability by campsite type,
   amenities, group size, or minimum nights.
6. As a user, if a campground/campsite is not available for my desired dates,
   I can create an alert to be notified when it opens up.
