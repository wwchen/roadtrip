# Private (PII / identity / session) tables.
#
# DATA from these tables is excluded from pg_dump snapshots via
# --exclude-table-data so that prod user identities are NEVER cloned into
# a sandbox.  The CREATE TABLE DDL is still included so the restored schema
# matches flyway_schema_history (Flyway must not re-run those migrations).
#
# A guard test (backend/src/test/kotlin/ca/floo/roadtrip/config/
# SandboxPrivateTablesTest.kt) derives the full set of user-scoped tables
# from the migration SQL files and asserts it equals this list — a new
# user-scoped table added without updating this file will fail the build.
#
# After restore, scripts/sandbox_seed_users.sql re-seeds app_user and
# user_role with two fixed sandbox-only users (will/matt @sandbox.local).
app_user
user_identity
user_session
user_role
user_settings
