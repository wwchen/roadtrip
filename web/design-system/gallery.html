Interactive / brand

Blue (--rt-brand) is the only interactive color. Green (--rt-avail) means availability, never "click me." Layer hues are map identity only.

--rt-brand-text is for blue as text. --rt-brand is tuned for solid fills (white-on-blue) and reaches only 4.05:1 as text on --rt-surface, under AA.

SecretField mountSecretField(el, {label, hint, help})

Write-only. With a hint it renders masked + Replace and getValue() returns null ("leave unchanged"). Without one it opens straight into entry. Try Replace, then Cancel.

DoubleConfirmButton mountDoubleConfirmButton(el, {label, confirmLabel, size})

Comfortable (≥44px) by default because it fires destructive actions. size: 'compact' is the opt-out for dense fixed-width rows. Click once to arm; it disarms after 3s.
